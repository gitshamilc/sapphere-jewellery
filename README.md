# SAPPHERE Jewellery

A premium, highly interactive digital catalog and realtime administration dashboard.

## Tech Stack
- Frontend: HTML5, CSS3, Vanilla JS
- Icons: Lucide Icons
- Realtime Sync: Supabase JavaScript SDK Client
- Bundler / Local Server: Vite

## Quick Deployment Info
1. Create a database on Supabase.
2. Run the SQL script from `supabase_setup.sql` in the SQL Editor.
3. Configure `config.js` with your project's credentials.
4. Deploy the repository to Vercel.
